# AGENTS.md

**This is a PUBLIC repository containing only public MCP catalog metadata.**

Before committing anything here, remember it is world-readable and permanent in git
history. Never add:

- personal data — emails, names, addresses, phone numbers
- internal working notes or status/submission logs
- local machine paths or usernames (`/home/<user>/...`)
- secrets, tokens, API keys, or `.env` values

Keep the repo to its public server metadata only: `server.json`,
`.well-known/mcp/server-card.json`, `mcp-config.json`, and `README.md`. Commit as a
GitHub noreply identity, never a personal email. See `CLAUDE.md` for the full guide.
